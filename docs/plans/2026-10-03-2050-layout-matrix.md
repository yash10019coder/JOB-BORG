# Decision Matrix: Profile Form Layout

## Current State
- **Profile page**: Single page with all fields + visa repeater
- **ExplicitAnswers page**: Separate page (`/explicit-answers/`) with free-text fields
- Users confused by two pages, field overlap

## Options

| Option | Layout |
|---|---|
| **A: Single Scrolling Page** | One long page: Basics → Locations → Work Auth → Citizenship → Salary → Custom Answers → Questions Panel |
| **B: Tabbed: Profile \| Auto-apply Answers** | Tab 1: Job search criteria (titles, tags, locations, resume). Tab 2: Auto-apply data (visa, citizenship, salary, custom, questions panel) |
| **C: Progressive Disclosure** | Start minimal. "Add work authorization" expands visa repeater. "Add salary" expands region dropdowns. Questions panel at bottom. |
| **D: Wizard/Onboarding** | Multi-step: Step 1 Basics, Step 2 Locations, Step 3 Work Auth, Step 4 Salary, Step 5 Custom, Step 6 Review |

## Recommendation: **Option B (Tabbed: Profile \| Auto-apply Answers)**

### Why Tabbed Wins
- **Clear separation of concerns**: "Job search" vs "Auto-apply data"
- **Power users** jump to Tab 2 directly
- **New users** start Tab 1, discover Tab 2 when they enable auto-apply
- **Mobile**: Tabs work well on mobile (swipe or dropdown)
- **Mental model**: Matches user intent ("I'm setting up my profile" vs "I'm configuring auto-apply")

### Derivation Display (Override Pattern)

```
Auto-apply will use: Citizen (USA)        [Override ▼]
                                    ↓ click
                              ┌─────────────────┐
                              │ Override for US │
                              │ [Citizen ▼]     │
                              │ [Save Override] │
                              └─────────────────┘
```

### Save Behavior
- **Tab 1 Save** → Updates Profile, triggers rematch, redirects to recommendations
- **Tab 2 Save** → Updates Profile (structured fields) + ExplicitAnswers (overrides), no redirect
